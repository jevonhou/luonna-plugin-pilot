# Luonna 插件试点

本仓库托管 Luonna v0.15 试点的 GitHub 协作内容包。预发行包用于验证 Luonna 的固定下载和插件生命周期。

| 试点 | 发行 | 内容 |
| --- | --- | --- |
| A1 | [v0.2.0](../../releases/tag/v0.2.0) | 仓库研究、Issue 草稿和 PR 草稿技能 |
| A2 | [v0.2.1](../../releases/tag/v0.2.1) | A1 技能、Issue 检查清单和 `resources.read` 声明 |

试点 App 在安装前会验证签名市场目录。每个发行页均列出内容资产的 SHA-256。这些资产是 Luonna 插件内容，本试点仓不提供 App 安装器。
