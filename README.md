# Luonna Plugin Pilot

This repository hosts the GitHub Collaboration content packages for the Luonna v0.15 pilot. The prereleases are test artifacts for validating fixed downloads and plugin lifecycle behavior in Luonna.

| Pilot | Release | Contents |
| --- | --- | --- |
| A1 | [v0.2.0](https://github.com/jevonhou/luonna-plugin-pilot/releases/tag/v0.2.0) | Repository research, issue draft, and pull request draft skills |
| A2 | [v0.2.1](https://github.com/jevonhou/luonna-plugin-pilot/releases/tag/v0.2.1) | A1 skills plus an issue checklist and the `resources.read` declaration |

The pilot App verifies the signed market catalog before installing. Each release lists the SHA-256 of its content asset. The assets are plugin content for Luonna, and this pilot repository contains no App installer.
